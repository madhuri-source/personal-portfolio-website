# Personal Portfolio Website

A personal portfolio website designed to showcase my technical skills, projects, and professional journey through a clean, modern, and interactive web experience.

## Overview

This portfolio serves as my digital presence, highlighting my background, technical skills, projects, and interests in technology. Built with a modern dark aesthetic, electric-blue accents, and glass-inspired elements, it combines visual simplicity with interactive functionality.

## Features

- Minimal dark-themed interface with electric-blue accents
- Glassmorphism-inspired design elements
- Fixed navigation with smooth scrolling
- Interactive hover effects and subtle transitions
- Dedicated sections for About, Skills, Projects, and Contact
- Responsive layout for different screen sizes

## Technology Stack

| Technology | Application |
|---|---|
| HTML5 | Structuring website content |
| CSS3 | Styling, layout, visual effects, and responsiveness |
| JavaScript | Interactive functionality and dynamic behavior |
